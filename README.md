# ecommerce-eda- sales & revenue trends
Exploratory data analysis on Olist Brazilian E-Commerce Dataset

##Project Overview
Exploratory Data Analysis on the Olist Brazilian E-Commerce dataset
to uncover sales and revenue trends across the 2016–2018 period.

##dataset used
Source: Kaggle- Brazilian E-Commerce Dataset (https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
Files used:
- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_order_payments_dataset.csv

##Analysis Performed
- Data Loading & Understanding
- Merging & Cleaning
- Data Transformation & Feature Engineering
- Univariate Analysis
- Bivariate Analysis
- Correlation Analysis
- Visualization
  
##Key Findings
- Revenue showed consistent growth from 2016 to 2018
- Credit card is the dominant payment method
- Higher installment counts correlate with higher order values
- Freight costs are proportionally higher for low-value orders

##Libraries used
- Pandas
- NumPy
- Matplotlib
- Seaborn
